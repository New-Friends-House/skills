# 작업일지 토글

`daily` 뒤가 정확히 `<일> <번호>`일 때 사용한다. 예: `daily 13 2`, `daily 13 2-1`.

- 날짜는 `Asia/Seoul` 기준 이번 달의 해당 일이며, 파일은 `work-log/YYYY-MM-DD.mdx`이다.
- `- [ ]` 또는 `- [x]` 바로 뒤 번호가 일치하는 줄만 찾는다. `2`는 `2.`, `2-1`은 `2-1.`과 대응하며 부분 일치로 찾지 않는다.
- 해당 줄의 `[ ]` ↔ `[x]`만 바꾼다. 문구·번호·카테고리·인덱스는 유지한다.
- 유효한 날짜, 기존 파일, 정확히 하나의 대상 줄을 확인할 수 없으면 변경하지 않고 이유를 알린다. 토글 요청을 새 일지나 항목 추가로 바꾸지 않는다.

대상 줄의 체크 상태만 바뀌면 완료다. 파일 경로와 바뀐 줄을 알린다.
