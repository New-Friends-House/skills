# No Check

현재 대화에서 구현을 소스 검토까지 마무리한다. 후속 작업에도 유지하며, 사용자가 나중에 특정 검증을 요청하면 그 범위만 허용한다. 모드 해제를 요청하면 기본 검증 지침으로 돌아간다. 다른 대화나 저장소의 기본 설정은 바꾸지 않는다.

- 소스 검색, 파일 읽기·편집, 셸 도구, Git 상태·diff 확인은 허용한다. 소스로 추론한 동작은 런타임 확인과 구분한다.
- 테스트 작성·실행, lint, format/fix, typecheck, 검증 스크립트, 검증 목적의 빌드는 생략한다.
- 브라우저·기기·시뮬레이터·에뮬레이터 자동화, 앱 실행, 화면 검사, 스크린샷, 런타임 진단을 생략한다. 이를 위한 개발 서버 시작, 기기 탐색·연결 요청도 하지 않는다. 이 경계는 사용하는 도구와 검증 위임에도 동일하게 적용한다.
- 검증 승인이나 기기 연결을 기다리지 않고 허용된 구현을 완료한다.

최종 답변에는 변경 사항과 소스 검토 범위, 실행하지 않은 검증을 적는다. 실제 기기 확인이 필요한 변경이라면 관련된 미확인 동작에 한해 대상 플랫폼·기기, 재현 절차, 기대 결과를 안내한다.
